# Самообновление программ с lis-carter.site

Как Wine Fox проверяет и ставит свои обновления, и как сделать то же в другой программе.
Этот файл можно целиком дать агенту, который работает над другой программой: в конце есть
готовое задание.

## Как это устроено

На сервере рядом с файлом программы лежит `latest.json`:

```
https://downloads.lis-carter.site/<программа>/latest.json
https://downloads.lis-carter.site/<программа>/<Программа>-<версия>-x86_64.AppImage
```

```json
{"version": "0.10", "file": "WineFox-0.10-x86_64.AppImage",
 "url": "https://downloads.lis-carter.site/wine-fox/WineFox-0.10-x86_64.AppImage",
 "size": 123591160, "sha256": "efb7…0240"}
```

`latest.json` делает скрипт сборки, а не человек: версия берётся из кода, размер и SHA-256 —
из готового файла. Страница сайта может быть любой: программа её не читает.

## Выпуск версии

1. Поднять версию программы. Без этого обновление никому не предложится. В Wine Fox версия
   записана в двух местах: `winefox/__init__.py` (`__version__`) и `pyproject.toml`.
2. Собрать: `bash packaging/build-appimage.sh`. В `dist/` появятся AppImage и `latest.json`.
3. Выложить на сервер в `downloads.lis-carter.site/wine-fox/` оба файла. Сначала AppImage,
   потом `latest.json`: иначе программа скачает ещё не выложенный файл.
4. Обновить на странице сайта ссылку и номер версии. Это нужно людям, программа их не читает.

## Что делает программа

1. **Проверка.** При запуске (через несколько секунд, в фоне, если включена настройка
   «Проверять обновления при запуске») и по кнопке «Проверить обновления»:
   - скачать `latest.json` по HTTPS с таймаутом;
   - сравнить версии по числам (`0.10` новее `0.9`, это не строки);
   - если версия новее, показать окно «Вышла <версия>» с кнопками «Обновить» и «Позже»;
   - без новой версии при запуске промолчать, а по кнопке сказать «у вас последняя версия»;
   - ошибку сети при запуске только записать в лог, а по кнопке показать.
2. **Проверка `latest.json`** до использования: в `url` только `https://`, в `sha256` 64 hex-символа,
   `size` — число. Иначе это ошибка, а не обновление.
3. **Установка (Linux, AppImage):**
   - путь к текущему файлу берётся из переменной `APPIMAGE` (её ставит среда AppImage). Если её
     нет, программа запущена не из AppImage: предложить скачать с сайта, ничего не трогать;
   - скачать в ту же папку во временный файл `.<имя>.part`, считая SHA-256 по ходу, с прогрессом;
   - сверить размер и SHA-256. Не совпало: удалить `.part`, сообщить, старый файл не трогать;
   - `chmod 755` (разрешить запуск как программу);
   - `rename` (`os.replace`) временного файла поверх текущего, под тем же именем. Так файл
     заменяется атомарно, а работающая программа продолжает держать старый, пока не закроется;
   - нет прав на запись в папку: показать ошибку, ничего не менять.
4. **Перезапуск.** Окно «Установлена <версия>» с кнопками «Перезапустить сейчас» и «Позже».
   Перезапуск: запустить тот же путь (`APPIMAGE`) отдельным процессом (новая сессия, без
   stdin/stdout) и закрыть текущую программу. Из окружения перед этим убрать `APPIMAGE`, `APPDIR`,
   `ARGV0`, `OWD` и всё, что указывает внутрь `APPDIR` (`PYTHONHOME`, `LD_LIBRARY_PATH`…): эта папка
   исчезнет, когда старая программа закроется.

## Где это в Wine Fox

| Что | Файл |
|---|---|
| Проверка, скачивание, сверка, замена | `winefox/updates.py` (`check()`, `install()`) |
| Настройка `check_updates` | `winefox/config.py` |
| Слоты `checkUpdates`, `installUpdate`, `restartApp` | `winefox/gui/backend.py` |
| Окна и проверка при запуске | `winefox/gui/qml/Main.qml` (`showUpdate`, `updateDialog`, `restartDialog`) |
| Переключатель и кнопка | `winefox/gui/qml/SettingsPage.qml` («Обновления») |
| `latest.json` | `packaging/build-appimage.sh` (в конце; `UPDATE_BASE` — адрес папки на сервере) |

Для тестов адрес `latest.json` меняется переменной `WINEFOX_UPDATE_URL`.

## Задание для агента другой программы

> Добавь в программу самообновление по схеме из `SELF-UPDATE.md` (приложен), с сервера
> `https://downloads.lis-carter.site/<имя-программы>/`.
> 1. Скрипт сборки после сборки пишет `latest.json` рядом с файлом программы: `version` из кода
>    программы, `file`, `url` (`https://downloads.lis-carter.site/<имя-программы>/<файл>`), `size`,
>    `sha256`.
> 2. Настройка «Проверять обновления при запуске» (включена по умолчанию), кнопка «Проверить
>    обновления» в настройках рядом с номером текущей версии, окно «Вышла <версия>» с кнопками
>    «Обновить» / «Позже», окно «Перезапустить сейчас» / «Позже» после установки.
> 3. Проверка и установка — как в разделе «Что делает программа»: HTTPS, сравнение версий по
>    числам, проверка полей `latest.json`, скачивание во временный файл рядом с текущим, сверка
>    размера и SHA-256, `chmod 755`, атомарное переименование поверх текущего файла под тем же
>    именем, перезапуск с очищенным окружением. Всё в фоне, без зависания интерфейса.
> 4. Если программа выходит не как AppImage, спроси меня, как её ставить и заменять (Windows:
>    работающий .exe нельзя перезаписать, нужен отдельный шаг замены после выхода).
> 5. Небольшой тест без сети: подмени загрузку локальными данными и проверь новее/не новее,
>    битый `latest.json`, неверную SHA-256 (старый файл не тронут), успешную замену.
> 6. При каждом выпуске поднимай версию программы.
